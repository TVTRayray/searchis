## 一、已确认（含对原需求的修改）

**1. 数据模型**
- **文本片段**（现有）：新增 `language` 字段（plain/bash/sql/yaml/json/toml/ini…），只用于语法高亮。Bash 命令归在这一类。
- **文件模板**（新增）：可以是任意文件，md 和 xlsx 额外支持“带格式复制”。不提供渲染引擎，不内置编辑器，编辑交给外部软件（Typora、WPS 等）。
- **key 必填**：导入时（包括自动导入）根据文件名自动生成 key，重复时加数字后缀，列表里标记“自动导入”，提醒用户检查。
- **文件模板不支持“敏感”标记。**

**2. 分组（新增概念）**
- 分组是树状层级，**文本片段和文件模板都可以放进分组**，和标签并存，标签继续保留。
- 磁盘上的 `~/.local/share/searchis/templates/` 按分组建子目录，“未分组”对应 `templates/` 根目录。
- 在管理界面重命名或移动分组时，同步修改对应目录。
- 只能在 Searchis 内部的分组之间移动，不引用外部位置的文件。

**3. 存储与外部改动的同步**
- 文件以明文存放，元数据存进加密库：key、标题、标签、分组、置顶、使用次数等。
- 打开管理窗口时扫描模板目录，规则如下：
  - **按 inode 识别文件，内容哈希作为兜底**，保证外部改名或移动后元数据不丢。
  - 文件在子目录之间移动，视为改变分组。
  - **目录里新出现的文件自动导入。**

**4. 管理界面的文件操作**
- **新建**：导入已有文件（支持拖入），或新建空白 md/xlsx。
- **其他操作**：用默认软件或指定软件打开、重命名、删除。
- **删除进入 Searchis 自己的回收站**：文件移到 `templates/.trash/`，恢复时连同元数据一起恢复；彻底删除时才删掉文件。

**5. 快搜窗口快捷键**

| 按键 | 文本片段 | 文件模板 |
|---|---|---|
| Enter | 复制 | 带格式复制 |
| Ctrl+Enter | 粘贴 | 带格式复制后自动粘贴 |
| Shift+Enter | 无操作 | 导出到默认目录 |
| Ctrl+O | 无操作 | 用默认软件打开 |
| Ctrl+E | 打开管理窗口编辑 | 打开管理窗口编辑（与文本片段一致） |
| Ctrl+N | 新建（不变） | 同左 |

**6. 带格式复制**
- **md**：剪贴板同时放入 `text/html`（用 pulldown-cmark 转换）和 `text/plain`（markdown 源码）。
- **xlsx**：复制单个工作表已用区域的格式和值，不带公式；同时提供 `XML Spreadsheet`、`text/html` 和 TSV 三种格式。需要公式时改用导出文件。
- **其他文件类型**：放入 `text/uri-list`。
- 由 Searchis 自己持有 X11 剪贴板（Tauri 剪贴板插件不支持自定义格式）。**已接受的风险**：Searchis 进程退出后，Klipper 通常只保留纯文本，富文本格式会丢失。

**7. 导出**
- 默认导出到 `~/Downloads`，可以在设置里修改。
- 文件名格式 `标题_YYYY-MM-DD.扩展名`，重名时加 `(2)`。
- 导出后弹出提示，显示文件路径。

**8. 搜索**：初版不做全文搜索，文件模板只按 key、标题、标签搜索。

**9. 连带改动**
- **schema 升到 v4**，新增或修改：
  - 新增分组表
  - 片段增加分组 ID 和 `language` 字段
  - 新增文件模板相关字段：相对路径、inode、内容哈希、扩展名等
- **备份**：改为 zip 格式，包含模板文件和分组目录结构。
- **回收站**：文件系统操作和数据库事务不是原子的，需要设计补偿或校正逻辑。
- **PRD**：修改 A-03 和 §3.4。“文件、Markdown 是非目标”的表述移除；富文本编辑和表单填充仍然是非目标。

**10. 视觉方向**
- **废弃液态玻璃**：SPEC-17～19 的玻璃配方整体回退，`backdrop-filter` 全部去掉，所有表面改为不透明。
- 浅色主题改用“植物 Botanical”，深色主题改用“暖炭 Ember”，两套共用同一套形状和字体（详见第二部分第 6 节）。

## 二、新增的 UI 需求

**1. 全局**
- **删除 `HeaderBar`**（目前 `src/App.tsx` 仍在使用它）。它的三个按钮（快捷键速查、主题切换、设置）移到管理窗口左栏最下方，横向排列；同时删掉左栏标题旁那个重复的设置按钮。

**2. 管理窗口（方案 A：统一分组树，列表里按类型筛选）**
- 保留三栏布局。
- **左栏**，从上到下：
  - 全部、固定、最近使用
  - 分组树：可折叠，带“+”新建按钮，包含“未分组”
  - 标签：整块可折叠
  - 回收站
  - 底部按钮栏
- **中栏**：
  - 顶部是过滤输入框和“+”下拉菜单（新建片段 / 新建 md / 新建 xlsx / 导入文件）。
  - 下方是类型筛选：全部、文本、文件。
  - 列表里两类条目混排，每行显示类型图标、标题、key、类型徽标。文件显示扩展名，文本在 language 不是 plain 时显示语言名。
  - 支持拖入文件，导入到当前分组。
- **右栏选中文本片段时**：在现有表单基础上增加“分组”和“语言”下拉框，内容区按 language 做语法高亮。
- **右栏选中文件模板时**：
  - 元数据表单：标题、key、分组、标签、固定。
  - 文件信息卡片：图标、文件名、大小、修改时间。
  - 操作按钮：打开、打开方式…、导出、带格式复制；“放入回收站”放在右上角。
  - **不预览文件内容。**

**3. 快搜窗口（方案 Q-A）**
- 保持简洁。
- **结果行**：左边是类型图标（文件按扩展名，文本按 language），中间是标题，副标题显示 key、分组、使用次数，右边是类型徽标和 `Ctrl+N` 序号。
- **底栏快捷键提示随选中项切换**：
  - 选中文件时：带格式复制 ↵ ／ 粘贴 Ctrl+↵ ／ 导出 Shift+↵ ／ 打开 Ctrl+O ／ 编辑 Ctrl+E ／ 关闭 Esc
  - 选中文本时：复制 ↵ ／ 粘贴 Ctrl+↵ ／ 编辑 Ctrl+E ／ 关闭 Esc
- 不做 Ctrl+K 动作面板。

**4. 设置页（方案 S1）**
- 左栏和管理窗口左栏同宽、同样式，内容换成分节导航：
  - 返回片段
  - 快捷键与启动
  - 粘贴行为
  - 外观主题
  - **文件与导出（新增）**
  - 检索与数据
  - 备份与重置
  - 关于
- “文件与导出”包含：
  - 导出目录（可选择）和文件名规则说明。
  - 模板目录（只读，带“打开”按钮），并说明文件以明文存放。
- “关于”从弹窗改为设置里的一个分节。

**5. 快捷键速查弹窗**：按“文本片段 / 文件模板”分别列出快捷键。

**6. 视觉规范：浅色「植物」+ 深色「暖炭」**

两套主题共用的形状和排版：

| 项目 | 规范 |
|---|---|
| 圆角 | 窗口 26px；卡片、代码块 18px；列表行 14px；输入框、按钮、快捷键标签、类型徽标都是胶囊形（999px） |
| 标题字体 | `"Playfair Display", "Noto Serif CJK SC", serif`。只用在 ≥18px 的标题：详情标题、设置分节标题、空状态。英文单词可以用斜体强调；**中文不用斜体**，因为中文斜体是机器倾斜，效果差 |
| 正文字体 | `"Source Sans 3", "Noto Sans CJK SC", sans-serif`；等宽字体沿用 JetBrains Mono |
| 小标签 | 小标签和按钮文字加字距 0.04–0.06em；不全大写 |
| 图标 | lucide 的 `strokeWidth={1.5}`；文件类型图标放在淡色圆形底上 |
| 按钮 | 主按钮实心；次要按钮描边；每个界面最多一个主按钮 |
| 输入框 | 填充底色，无边框；获得焦点时出现 2px 强调色光环，并带偏移 |
| 纹理 | 窗口背景加 SVG 纸张颗粒层（`pointer-events:none`）；浅色约 0.06，深色约 0.035，最终数值在实机上调 |
| 动效 | 快搜窗口追求键盘操作的速度：选中、悬停的过渡 ≤150ms，弹出 ≤200ms。管理窗口的悬停过渡可以用 300ms ease-out。列表不做卡片上浮。遵守 `prefers-reduced-motion` |
| 不采用 | 参考文件里的超大标题、错位网格、拱形图片、全大写按钮 |

## 三、仍待定的问题

**功能**
1. 分组嵌套层数：不限，还是最多 3 层？
2. 外部新建的子目录是否自动变成分组？（建议：是）
3. 自动生成 key 时，中文文件名怎么处理：转拼音首字母、保留中文，还是用 `file-N`？
4. 标题和磁盘文件名是否双向联动？
5. 外部删除了文件，元数据怎么处理：直接删除、进回收站并标记“文件缺失”，还是显示为失效？
6. 同一分组目录下文件重名时：自动加后缀，还是提示用户？
7. 只放了文本片段的分组，是否也建空目录？（建议：建，保证目录树和分组树完全对应）

**视觉**

8. **字体来源**：建议把 Playfair Display 和 Source Sans 3 的拉丁子集（woff2）打包进应用，中文退回系统里的 Noto CJK（Arch 的 `noto-fonts-cjk`）。是否同意？
9. **快搜窗口是否保留透明窗口**：26px 圆角需要透明窗口和 KWin 混成器支持。另一个选择是去掉透明，改成直角或系统圆角的不透明窗口。
10. **纸张颗粒纹理的不透明度**：在实机上最终确定。
11. **深浅两套的强调色不同**：浅色是森林绿和鼠尾草绿，深色是陶土色；两者靠赤陶色（浅色主按钮的悬停色）衔接。是否接受这种差异，还是深色也改用鼠尾草绿？
