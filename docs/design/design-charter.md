# Design Charter: Searchis

> 每个视觉 spec 的第一句必须引用本宪章。
> 来源：`docs/prds/file-templates-ui-requirements.md` 第一部分第 10 节、第二部分；PRD D-17；定版预览 `docs/prds/file-templates-ui-theme-preview.html`。取代 Phase 9 液态玻璃设计源。

## Design Read（一句话）

KDE 桌面上的键盘优先效率工具（快搜浮窗 + 三栏管理窗口），面向长时间使用的个人用户；气质是温暖、安静、有纸张质感的工作台——浅色“植物 Botanical”、深色“暖炭 Ember”，不透明、不炫技。

## 三旋钮

- DESIGN_VARIANCE（变化度 1-10）：3 — 布局规整，只在标题字体与纸张颗粒上留个性。
- MOTION_INTENSITY（动效强度 1-10）：2 — 快搜窗口以速度为先（≤150ms / ≤200ms），管理窗口悬停 ≤300ms ease-out。
- VISUAL_DENSITY（视觉密度 1-10）：6 — 信息型列表，三栏同屏，但行高与留白保证可扫读。

## 设计原则

1. **纸面而非玻璃**：所有表面不透明，层次靠底色阶梯与柔和阴影，不使用 `backdrop-filter`、半透明面板或氛围光。
2. **速度优先于装饰**：快搜窗口的任何视觉效果不得拖慢键盘操作；列表不做卡片上浮。
3. **两套主题，一套骨架**：浅色与深色只换颜色；圆角、字体、间距、布局完全一致。
4. **类型一眼可分**：文本片段与文件模板混排时，靠类型图标（淡色圆形底）与徽标（语言名或大写扩展名）区分，不靠颜色单独传达。
5. **每个界面最多一个主按钮**：主按钮实心，其余描边或文字按钮。

## 签名元素（产品识别点）

- Key 与快捷键标签的胶囊形，`Ctrl+N` 序号贴右。
- 匹配高亮使用暖金色 `--color-highlight`，而非强调色。
- 标题使用 Playfair Display 衬线（仅 ≥18px：详情标题、设置分节标题、空状态）；英文可斜体强调，中文不斜体。
- 窗口背景的 SVG 纸张颗粒（浅色约 0.06，深色约 0.035）。
- 敏感片段的遮挡样式保持现状（默认遮挡、会话级显隐）。

## 反模式（禁止清单）

- `backdrop-filter`、玻璃 token、氛围光、半透明面板。
- 超大标题、错位网格、拱形图片、全大写按钮（参考稿中未采用的元素）。
- 组件内硬编码颜色、圆角、阴影；无语义的颜色变量。
- 列表卡片悬停上浮、弹跳或视差动画。
- 中文斜体；声明未随包发货的字体。
- 只靠颜色表达状态（必须配合图标或文字）。
- 在界面中渲染 Markdown 或预览文件内容。
