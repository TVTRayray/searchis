## 非目标

不借发布之机重构架构、添加遥测、跨平台、云同步、Markdown 或新交互。

## 发布与诊断契约

- 发布元数据必须记录 commit、版本、构建命令、Rust/Node/Tauri/SQLCipher 版本和 Arch 包快照日期。
- SHA-256 由最终字节生成并在验证后不再修改可执行文件。
- 诊断仅允许 PRD 第 13 节指标；不联网，默认保留 7 天，清除操作可观察。
- 数据库迁移失败保留原文件；密钥错误不得明文降级；发布替换不得删除用户数据目录。

## 失败门槛

| 发现 | 结论 | 处理 |
|---|---|---|
| 正文/密钥/查询词进入日志或 a11y | 阻止发布 | 退回对应 spec/Coder，修复并重测 |
| 任一事务出现部分提交/不可恢复删除 | 阻止发布 | 退回所有者 spec |
| 性能不达标 | 不宣称通过 | 记录样本与瓶颈，Master 决定窄修复 spec |
| 目标机缺依赖且提示不可执行 | 阻止发布 | 修复依赖说明或构建策略 |
| Global Menu 小部件缺失 | 不阻止 | 只要应用内降级通过 |
